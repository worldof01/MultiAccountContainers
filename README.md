# Chromium Multi Container

A browser extension for managing multiple isolated containers/tabs based on Chromium technology. Works seamlessly with Chrome, Edge, Brave, and other Chromium-based browsers.

## Features

- Isolated container management
- Easy tab grouping and switching
- Lightweight and fast

## Installation (Developer Mode)

Since the extension is not yet published on the Chrome Web Store, you need to load it manually in developer mode.

### Step-by-step guide

1. **Open the Extensions page**  
   Visit `chrome://extensions` (or `edge://extensions` in Microsoft Edge).  
   ![Extensions page](extensionpic.jpg)

2. **Enable Developer Mode**  
   Toggle the **Developer mode** switch in the top-right corner.  
   ![Developer mode](help01.jpg)

3. **Load unpacked extension**  
   Click the **"Load unpacked"** button that appears after enabling Developer mode.  
   ![Load unpacked](help02.jpg)

4. **Select the extension folder**  
   In the file dialog, navigate to the folder where you saved the extension files (the folder containing `manifest.json`). Select the folder and click **Select Folder** (or **Open**).  
   ![Select folder](help03.jpg)

The extension icon should now appear in your browser toolbar. You're ready to use it!
