# Chromium 多容器扩展

一个用于管理 Chromium 系浏览器（Chrome、Edge、Brave 等）中多个独立容器/标签页的浏览器扩展。

![扩展主视图](extentionpic.jpg)
*扩展主视图*

## 安装（开发者模式）

由于该扩展尚未发布到网上应用商店，您需要手动加载它。

1. **打开扩展程序页面**  
   前往 `chrome://extensions`（在 Microsoft Edge 中为 `edge://extensions`）。

2. **启用开发者模式**  
   打开右上角的**开发者模式**开关。  
   ![开发者模式开关](help01.jpg)

3. **点击“加载已解压的扩展程序”**  
   启用开发者模式后，会出现一个新按钮。点击**加载已解压的扩展程序**。  
   ![加载已解压的扩展程序按钮](help02.jpg)

4. **选择扩展文件夹**  
   在文件对话框中，导航到包含扩展文件的文件夹（确保 `manifest.json` 在其中）。选择该文件夹并点击**选择文件夹**（或**打开**）。  
   ![选择文件夹](help03.jpg)

扩展图标应出现在浏览器的工具栏中。现在您可以使用它了。

## 功能特性

- 为不同的浏览场景管理独立的容器
- 快速切换和分组标签页
- 轻量级，基于 Chromium 的多进程架构
